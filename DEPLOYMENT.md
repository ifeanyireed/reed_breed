# ReedBreed Backend Deployment Guide (Hostinger)

This guide outlines the steps to deploy the Laravel + Prisma backend to Hostinger.

## Step 1: Database Setup (phpMyAdmin)
Import the structure and initial data.
1.  Open **Hostinger hPanel** > **Databases** > **phpMyAdmin**.
2.  Enter the database `u560700323_reedbreedcc_db`.
3.  Go to the **Import** tab.
4.  Upload and run **`backend/schema_dump.sql`** (Creates Tables).
5.  Go to the **Import** tab again.
6.  Upload and run **`backend/seed_data.sql`** (Creates Admin & Plans).
    *   *Default Admin: `admin@reedbreed.cc` / `admin123`*

## Step 2: Prepare Environment File
1.  Locate **`backend/.env.production`**.
2.  Ensure `DB_HOST=127.0.0.1` (this works when the app and DB are on the same server).
3.  Rename this file to just **`.env`** locally before uploading.

## Step 3: Upload Backend Files
1.  Zip the `backend` folder (Exclude `node_modules` and `vendor` folders).
2.  In Hostinger **File Manager**, upload the zip to the root directory (outside of `public_html`).
    *   Path should look like: `/home/u560700323/backend/`
3.  Extract the files.

## Step 4: Web Entry Point (The "api" folder)
To make your API accessible via `https://reedbreed.cc/api`:
1.  In `public_html`, create a folder named `api`.
2.  Copy all files from `backend/public/` into `public_html/api/`.
3.  Edit `public_html/api/index.php` and update the paths to point to your backend:
    *   Change: `require __DIR__.'/../vendor/autoload.php';`
    *   To: `require __DIR__.'/../../backend/vendor/autoload.php';`
    *   Change: `$app = require_once __DIR__.'/../bootstrap/app.php';`
    *   To: `$app = require_once __DIR__.'/../../backend/bootstrap/app.php';`

## Step 5: Final Server Commands (SSH)
1.  Connect via SSH to your Hostinger account.
2.  Run these commands in order:
    ```bash
    cd backend
    composer install --optimize-autoloader --no-dev
    php artisan key:generate
    php artisan optimize
    php artisan storage:link
    ```

## Step 6: Update Frontend
1.  Update your Frontend environment variables (Vercel/Hostinger).
2.  Set `NEXT_PUBLIC_API_URL=https://reedbreed.cc/api`.
